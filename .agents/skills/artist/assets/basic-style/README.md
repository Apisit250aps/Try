# Basic Style Examples

Original reference images for the Wayu Arts `basic-style` identity described in
[`../../references/style-guide.md`](../../references/style-guide.md).

This folder holds the reference images that define the look of the style —
bold black outlines, chibi proportions, rosy cheeks, pastel accent colors,
and short sticker-style captions. Treat them as a whole set for the overall
feel of Wayu Arts rather than copying any single image detail-for-detail.
Some examples include technology names or logo-like marks. They demonstrate
style, not clearance or an instruction to reproduce those details; apply the
[stock rules](../../references/stock-guidelines.md) for original generic delivery.

The three original images are retained unchanged: [ref-1.png](ref-1.png),
[ref-2.png](ref-2.png), and [ref-3.png](ref-3.png). This folder was previously
named `style-examples`. Pixel references live separately in
[pixel-style](../pixel-style/README.md).

Add more example images here over time as the collection grows. Suggested
naming: `<subject>-<variant>.<ext>` (e.g. `developer-chibi-front.png`,
`cat-sticker-example.png`), so examples stay easy to browse.
