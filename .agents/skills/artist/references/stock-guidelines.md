# Stock and commercial illustration

Apply this mode when the brief requests reusable stock/commercial assets. Keep
the existing Wayu Arts collection original and generic. These production
conventions do not establish marketplace acceptance or legal clearance.
For reference licenses, provenance and publishing context, read
[rights-accessibility.md](rights-accessibility.md). A generic redesign does not
by itself establish that every input or output is cleared for sale.

- Design original characters; avoid recognizable copyrighted mascots, celebrity
  likenesses, copied stock compositions, brand marks and artist signature styles.
- Use generic props rather than branded equivalents. Preserve the function and
  narrative intent of the object; flag a conflict if substitution changes it.
- A generic laptop, code editor window, blank badge, gear, or `</>` / `{ }` symbol
  can replace a branded device, IDE, uniform badge or programming-language logo.
- Specify no incidental logos or brand names; inspect actual output for them.
- Do not silently add a caption. If the brief requests one, keep its exact
  wording; for the Wayu Arts preset prefer short 2–5 word captions in a bubble,
  note or banner. Prefer symbols when they communicate the intended idea.
  Check spelling rather than claiming generated text is reliable. "No readable
  text" is appropriate only when the asset should contain no requested caption.
- Isolated assets need clean silhouettes, edges, padding and actual alpha when
  transparency is requested. A white or checkerboard background is not alpha.
- Do not trace a copyrighted illustration or redraw a brand mark to bypass the
  originality requirement. Retain editable raster sources/layers when produced.

Outside stock mode, follow the user's project brief and approved visual canon;
do not silently substitute story-critical assets under stock defaults.
