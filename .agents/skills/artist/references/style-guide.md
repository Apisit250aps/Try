# Wayu Arts — Basic Style Preset (Canonical Reference)

This is the **single source of truth** for Wayu Arts `basic-style`
inside Artist. Use it for basic-style work and as the default for a new project
without a specified look. An explicit brief or approved project art bible can
choose another visual style. Do not apply this preset's proportions, mood or
palette over a different established project look.

For pixel art, use [pixel-style.md](pixel-style.md) and its separate examples;
smooth rounded strokes and continuous curves below belong to basic-style.

Reference imagery that illustrates this style lives alongside this file in
[`../assets/basic-style/`](../assets/basic-style/).
Use those images for the overall look. Some contain incidental technology names
or logo-like marks; those are not part of the preset contract and should not be
reproduced under its original/generic stock rules. Existing images are visual
references, not certified rights-cleared stock deliverables.

## Identity

**Wayu Arts** — cute, chibi-inspired illustration style used for stock
illustrations, stickers, developer/character illustrations, UI illustrations,
educational content, social assets, and commercial design work.

## Character Proportions

- Oversized head relative to body (chibi ratio, roughly 1:1 to 1.5:1 head-to-body height)
- Small, simplified body
- Soft, rounded proportions everywhere — avoid sharp angles
- Rounded face shape (circle/oval-based)
- Rosy cheeks (soft pink/coral circular or oval blush)
- Simple eyes: dots, curved lines, or closed happy-eye arcs — avoid detailed/realistic eyes
- Friendly, expressive faces (smiling, content, curious)
- Expressive hands, simplified to a few fingers or mitten-like shapes

## Line Work

- Thick, bold outlines that read clearly even at small sizes
- Rounded line caps and rounded line joins (no sharp miter joins)
- Outline color: bold black or very dark charcoal — match the reference
  images in [`../assets/basic-style/`](../assets/basic-style/) rather
  than a strict single hex
- Suggested outline color: `#1A1A1A` (near-black) or `#2B2118` (dark charcoal-brown)
- Consistent stroke width across a single character/scene

## Shapes

- Smooth, organic shapes — avoid rigid geometric silhouettes
- Minimal visual noise — every shape should serve the character or composition
- Flat colors preferred; avoid excessive gradients, filters, or heavy shading

## Accents & Motion Marks

Small supporting details give the style its energy, visible throughout the
reference images:

- Simple heart icons, small colored badge icons (e.g. a cross, a code
  bracket), and sparkle/flick "motion mark" accents scattered around the subject
- Speech bubbles, sticky-note, or banner shapes for short captions (see
  Text in Artwork below)
- Use accents sparingly and in the same pastel/warm palette — they should
  frame the subject, not overwhelm it

## Color Palette

Soft pastel palette. Core palette (extend as needed, keep pastel/soft):

| Role         | Color                   | Hex (approx)          |
| ------------ | ----------------------- | --------------------- |
| Teal accent  | Soft teal               | `#7FCDBB`             |
| Coral accent | Warm coral              | `#F4978E`             |
| Pink accent  | Soft pink               | `#F7C6D9`             |
| Cream base   | Warm cream              | `#FFF6E9`             |
| Blue accent  | Soft blue               | `#A7D8F0`             |
| Warm accent  | Warm peach/orange       | `#FFC98B`             |
| Outline      | Bold black / near-black | `#1A1A1A` / `#2B2118` |

Use 3–5 colors per character/scene to keep the look clean and cohesive.

## Composition & Framing

- Both full-body and bust/half-body (waist-up or shoulders-up) framing are
  valid — many reference pieces use a close bust crop with expressive hands
  raised (thumbs-up, fist pump, hands near chest)
- A flat white background with scattered accent icons/captions around the
  subject ("sticker sheet" composition) is a valid alternative to a fully
  transparent isolated cutout — choose per the target use case
- Keep the subject centered and readable; accents should frame, not crowd,
  the character

## Mood

- Cheerful, friendly, approachable
- Modern sticker/illustration aesthetic
- Suitable for commercial/stock illustration conventions (see
  [stock-guidelines.md](stock-guidelines.md)); acceptance is not guaranteed

## Collection Consistency

When producing multiple images for the same collection (e.g.
`wayu-arts/developer`, `wayu-arts/office`, `wayu-arts/education`,
`wayu-arts/medical`, `wayu-arts/business`, `wayu-arts/finance`), keep these
elements consistent across every piece:

- Head/body proportions
- Eye style
- Cheek design
- Outline thickness
- Color palette
- Shading approach (flat vs. minimal shading)
- Object detail level
- Composition density
- Overall visual personality

## Text in Artwork

Short, punchy captions and speech-bubble text are a defining part of this
style (see the reference images) — this is not a "no text" style, but text
must stay brief and simple:

- Keep captions short: roughly 2–5 words, title-style phrasing — e.g.
  "Good Code Good Mood", "Care for a Brighter Tomorrow ♥" — never full
  sentences or paragraphs
- Contain captions in a speech bubble, sticky-note, or banner shape rather
  than loose floating text
- Pair captions with a heart or simple symbol rather than extra punctuation
- Prefer symbols over words when a symbol reads clearly on its own:
  `</>` `{ }` `✓` `!` `♥`
- Avoid real brand/product names in any labels (e.g. book spines, screens) —
  use generic equivalents per [stock-guidelines.md](stock-guidelines.md)
- Image models frequently misspell or garble anything longer than a short
  phrase, so keep generated text minimal and double-check spelling

## Originality & Copyright

- Original character designs only
- No trademarks, logos, or brand names
- No copyrighted characters or mascots
- No celebrity likenesses
- No imitation of a specific living artist's signature style
- Prefer generic objects (generic laptop, generic code editor, generic
  programming symbols) over branded equivalents

See [stock-guidelines.md](stock-guidelines.md) for commercial/stock detail.
