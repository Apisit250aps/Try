Keep scale, costume, lighting and identity stable across views. Label left/right
profile and asymmetries. Enter output paths only for files actually produced;
mark a planned or prompt-only view as such.
For pixel sheets, apply the 128×128 minimum to each drawing cell; record grid
targets separately from verified dimensions. Keep baseline and pixel scale fixed.
Distinguish neutral construction views from expressive perspective views; record
landmark alignment and volume mismatches. Unknown back/hidden details stay draft
proposals until selected. A sheet spec is not an actual produced model sheet.
