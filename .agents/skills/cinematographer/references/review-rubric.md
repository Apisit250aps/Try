# Review, acceptance and revision

This is a local evaluation instrument (S04), not a scientifically calibrated
quality scale. Use the brief's stricter acceptance criteria. Evidence levels:
text/spec inspection, static machine check, rendered-frame inspection, temporal
clip/animatic inspection, independent agent trial, actual receiver response and
audience test. Report each separately.

## Hard failures before scoring

Unapproved canon/script/reveal changes; missing indispensable shot/action;
contradictory geography/state without a declared purpose; fabricated input,
artifact, approval or test; unsupported provider controls represented as executed;
or impossible handoff references. These need correction or an explicit blocker,
not a high average score. Deliberate discontinuity is assessed against its stated
purpose and recovery, rather than automatically penalized.

## Observable rubric

Score each applicable dimension 0–2: **0** absent/contradictory, **1** usable with
a specified gap, **2** coherent at the available evidence level. For spec-only
work, a 2 describes the plan, never proof of visual success. Mark visual/timing
dimensions unmeasured when no artifact exists; do not silently score them as 2.

| Dimension | Observable checks | Next test / remedy |
| --- | --- | --- |
| Intent and information | Every essential beat has a shot path; all required clues visible only in allowed windows; audience/character knowledge separated. | Trace beat→shot and first disclosure; if missing, redesign coverage before style. |
| Composition/readability | Named primary read, gesture/contact and needed context; safe-area/ratio specified. | Inspect delivery-size frame/overlay; test required recognition with a viewer. |
| Spatial/action continuity | All primary cuts have compatible state, target and screen direction, or documented exception/reorientation. | Adjacent panels/clip review; restore contact/landmark or show the crossing. |
| Camera/optics | Viewpoint/FOV consistent; motion/focus separated; numbers have gate/units; zoom/dolly correctly distinguished. | Check projection/path or compare actual landmarks; simplify contradiction. |
| Light/look | Sources and motivation/expressive reason, quality/contrast and look version are traceable across states. | Inspect poses/reverses under same transform; correct spill/clipping/continuity. |
| Sequence/timing | Estimated primary durations total target within declared tolerance; alternates/handles separate; critical reads and trims named. | Time an animatic/cut with Editor; preserve inference while trimming. |
| Feasibility/medium | Action/path/asset demand fits stated resources; AI controls verified or marked unknown; fallback/attempt limit. | Bounded representative generation/physical/previs trial. |
| Handoff/revision | Stable IDs/upstream versions, real/missing locators, owner decisions and changed/stale dependencies explicit. | Receiver uses packet without guessing; retain response or unresolved request. |

Local planning gate: no hard failures; all applicable spec dimensions ≥1;
essential information, continuity and handoff ≥2; explain every 1. This gate is
a documented review policy, not a guarantee of artistic excellence. For rendered
delivery additionally require no unresolved essential-read/identity/contact defect
and actual target-size/temporal evidence; don't substitute arithmetic for playback.

For a controlled audience exercise, predeclare questions (who holds token, which
door, when clue noticed), sample and success threshold before viewing. Example
pilot criterion: 4 of 5 viewers answer all essential spatial/information questions
without coaching. This is a local pilot design, not a population-level inference
or a result claimed by this skill. Separate taste (“prefer wider”) from observed
failure (“could not identify which hand released token”).

## Diagnose and revise

Record shot/version and actual frame/time range → observation → intended effect
at risk → likely cause → smallest correction → retest. Severity: critical
(hard failure), major (essential inference/continuity/feasibility fails), minor
(polish without losing function), preference (alternative without demonstrated
failure). Review-only returns notes, not modified plans/assets.

Preserve prior versions; change upstream facts only within authorized scope.
Retest affected neighbors, board frames, prompts/clips and cut segments, not the
entire project by default. Two failed corrections on the same generation defect
lead to a simpler plan or limitation report. A corrected spec is implemented;
it becomes visually verified only after its artifact is inspected.

For repeatable trials use [scenarios](../tests/scenarios.md). For current evidence
and exclusions see [evaluation](../tests/evaluation.md).
