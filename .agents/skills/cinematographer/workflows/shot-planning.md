# From scene to a reviewable shot package

Use for a complete sequence; scale down to the requested shot/diagnosis. This
workflow is local synthesis, informed by P16/P18 in
[research notes](../research/notes.md). It is not a compulsory studio pipeline.

1. **Read the scene at its actual version.** Extract mandatory actions/dialogue,
   discoveries and audience order. Keep story facts separate from the planned
   performance and visualization. Record only consequential assumptions.
2. **Write the visual proposition.** Name the scene change and intended inference.
   Translate it into a small set of decisions about shared/isolated views,
   distance, reveal, motion and light. If brief is open, compare a materially
   different option and its cost. Consult [strategy](../references/visual-strategy.md).
3. **Map the playable space.** Locate actors/props/entrances/light sources, active
   axes and critical look targets. Test approach/contact/release, not only poses.
   Identify occlusions that would hide or prematurely reveal story information.
4. **Propose the primary sequence.** Assign stable shot IDs linked to scene and
   narrative/script beats. Every shot has a job and a start/end state. Test whether
   an unneeded cut or move can be removed. Add only useful protection: alternate
   reaction, readable prop or geographic bridge. Keep setup order separate.
5. **Specify the makers' needs.** Select camera/FOV/focus/motion and world lighting
   for the action and medium. Give Artist board start/key/end panels; give Editor
   critical read/hold/exit and handles. Record sound dependencies early. Use
   [camera](../references/camera-optics.md), [lighting](../references/lighting.md)
   and [continuity](../references/blocking-continuity.md) selectively.
6. **Budget before production.** Identify must-have shots, rig/set/reset costs,
   animation redraws/unseen surfaces, render/generation attempts and revision
   allowance. If time is cut, preserve the causal/reveal chain and legible contact
   before ornamental coverage. Offer a concrete reduced plan and its cost.
7. **Adapt to tools, if requested.** Keep the model-agnostic spec; create the actual
   provider adapter only after checking capabilities. Use
   [animation/AI guidance](../references/animation-ai.md); simplify a failing unit
   before requesting more elaborate camera motion. A spec-only task launches no
   generation merely to satisfy a template.
8. **Review the sequence and handoff.** Check state transitions, disclosure order,
   frame readability and duration arithmetic. With actual artifacts, inspect them
   at target size and in time; with text alone, label unresolved visual evidence.
   Use the [rubric](../references/review-rubric.md), retain revisions, and send
   the smallest packet with an actionable receiver question.
