# Worked critique examples

All fragments here are **original synthetic examples**, not observations of a
real film. These illustrate reasoning, not universal correct creative choices.
Use [report template](../templates/review-report.md) for complete records.

## Evidence before accusation

**Poor:** “Plot hole. The writer forgot the key. Fix the ending.”

**Better:** `CR-01`, script-A v2 S030/B02: brief asks viewers to infer how the
drawer opens. S010 places the sole key in Mai's coat; S030 shows Noon opening
the drawer, but the supplied complete S010–S030 contains no transfer or alternate
mechanism. Expected: a perceivable causal route under bible-v1 K2. Observed:
opening without that route (text review only). Major; observation high confidence,
cause medium (missing setup is a hypothesis). Owner: Screenwriter; dependencies:
Storyteller K2, S020 and shot plan SH030. Options: plant an unobtrusive transfer
(preserves the mystery's actor but costs attention), or propose a new drawer
mechanism to Storyteller (changes canon). Acceptance: new script supplies the
chosen route before use, without revealing the culprit if that remains locked;
later board/animatic readability remains unverified. State open.

**False-positive check:** if only S030 was supplied, replace the global absence
claim with “cause not established in this excerpt; earlier setup not-assessed.”
If K2 explicitly permits a remote unlock and that is planted, no key defect.

## Plot hole versus intentional mystery

Bible-v3 says only one twin can unlock the box. E01-S04 leaves the opener unseen;
E03 will reveal which twin. “Which twin?” is an open promise, not a contradiction.
Track audience knowledge and revisit the promised disclosure at E03.

Different evidence: bible-v3 also says neither twin is present and no remote or
other mechanism exists, but E01-S04 explicitly shows the box opening itself in
objective continuous action. A real conflict candidate exists. Check whether a
rule revision or unreliable presentation is authorized; do not explain it away
by inventing magic or call every mystery a blocker.

## Direct dialogue can be action

**Poor:** “Cut all exposition; show, don't tell.”

**Better:** script-B v1 S020 lines4–7 repeat a fact both characters already used
in line2 without changing either's action. This may stall the confrontation
(impact medium confidence; text only). Minor unless the repeated fact is the
required clue. Keep line8's direct confession: after three evasions it changes
the relation. Screenwriter could turn the repeated fact into an accusation
(more conflict) or remove one exchange (less processing time). Acceptance:
the chosen version preserves the clue and gives the listener a playable response;
read-through needed for vocal rhythm. Explicit speech itself is not the defect.

## Deliberate axis crossing and visual drift

**Poor:** “Crosses180°, so the cinematography fails.”

**Better:** shot-plan-C v4 SH02→SH03 proposes an axis crossing at the character's
loss of control; SH02 specifies a visible orbit and SH03 re-establishes the door.
No plan-level error established. Keep the disorientation; test whether viewers
can still identify the exit in an actual animatic. No claim the camera move was
watched. If the actual cut lacks both orientation cues and the escape depends
on them, return a located orientation-risk finding, not a mere rule violation.

For character drift, a reference's mark is on the **character's left** cheek.
A right-profile image may correctly hide it. Compare view/occlusion before
flagging absence. In two actual unobstructed left-profile views, cite the exact
cheek region and revisions. If only descriptions are available, this is a
textual consistency concern and visual match remains not-assessed.

## Tone and pacing with a cause hypothesis

**Poor:** “Boring. Add more cuts and funny music. Audience retention will double.”

**Better:** rough-cut-D v1, supplied elapsed00:12–00:18: the same readable warning
is presented twice while the locked grief brief asks for an unbroken recognition.
If actually inspected, the repetition supports an information-density concern;
it does not prove the six seconds alone cause disengagement. Editor can remove
the second warning (preserves quiet) or give it a new relational meaning (keeps
duration, more performance work). Verify first-view inference and the reaction
that follows. No measured engagement result exists. If only the script is
available, say S020/B03 and planned6s, not observed cut time.

## Missing sound and silent work

Script-E v1 calls for a bell; no audio exists. “The mix masks the bell” is
fabricated. Correct: bell's narrative role assessed from text; mix/intelligibility
not-assessed, owner Sound Designer when available. Verify with an actual sound
revision under intended playback conditions.

For a locked fully soundless30s animation, missing dialogue is N/A. A repeated
pose may intentionally create anticipation. Preserve the main-work silence;
propose a separate descriptive transcript/description path if access delivery
requires it. Do not claim captions alone communicate the visible story.

## Conflicting notes and valid disagreement

Artist says “hold the face longer so its expression reads”; Editor says “trim
the face so the reveal lands sooner.” Record both against cut-F v2 SH05, identify
the shared goal of the reveal and distinguish prescribed duration from concern.
OptionA: retain hold, reduce competing background detail; optionB: trim preceding
repetition and preserve face time. Trade-offs: asset work vs rhythm change.
Director chooses priorities; Critic recommends based on the actual cue, not rank.
No actual receiver acknowledgment is assumed.

A critic prefers naturalistic colors; a supplied surreal style bible locks
acid-green skies. With no evidenced readability or intent conflict, “use blue”
is a suggestion/preference, not a major defect. Director can validly retain green.
Record that decision and stop repeating the note as if it were unresolved error.

## High scores cannot close a blocker

Hypothetical assessed creative profile: intent3, narrative3, visual3. The final
delivery's required caption file is confirmed absent and the brief makes that a
release condition. Show the failed gate and blocker next to the profile; do not
announce “100% ready.” A concept sketch without that delivery condition would
not inherit this blocker. A file not supplied to the reviewer is `unknown`, not
automatically confirmed absent from production.

## Uncertain originality and rights

“A robot mourning its owner” resembles a trope. This alone cannot establish
plagiarism. If a user supplies two actual scenes, compare specific expression
with locators, disclose scope and request provenance/rights evidence as needed.
Do not certify clearance or infer illicit origin from absent C2PA metadata.
Creative originality analysis can continue separately from a legal determination.

## Fix verification and regression

CR-01 acceptance: key route perceivable before drawer opening; culprit identity
withheld. Script-A v3 adds S020/B04: Mai leaves the coat open and Noon takes the
key, face explicitly concealed. Text inspection verifies the key route but the
new close-up reflection now names Noon if a supplied board shows it. Reopen
the reveal constraint with new evidence; don't close both from “key added.”
If no board is supplied, mark that visual/reflection risk unverified, not observed.

Record `v2→v3`, authorization, changed S020/B04, preserved K2, downstream SH030
stale and exact acceptance results. Storyteller must check knowledge/canon;
Screenwriter owns script changes; Cinematographer checks reveal/camera realization.
Even if Director approves the script, Critic records what it actually verified.
On v4, evaluate the revised cause and reveal, not whether the maker used the
Critic's exact proposed dialogue. A later regression becomes reopened with new
revision evidence; prior verified history remains visible.
