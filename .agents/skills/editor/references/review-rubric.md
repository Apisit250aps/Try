# Measurable editorial review

Local evaluation design P18, not a validated psychometric scale or industry
certification. Use with [scenarios](../tests/scenarios.md). Score available
evidence only, identify same-author vs independent reviewer, and mark N/A with
reason. A text trial cannot earn rendered-media points by describing future QC.

| Dimension | Observable evidence for a complete response |
| --- | --- |
| Narrative / information | Each required beat has a location; causal prerequisites and protected reveal order survive; open comprehension questions are explicit. |
| Performance / rhythm | Select/trim/hold has a specific dramatic reason, local and whole-scene pacing consequence, plus a meaningful alternative where contested. |
| Continuity / intent | Geography, eyelines/action/prop/temporal state checked at relevant joins; intended violations have purpose and retain required anchors. |
| Time / media | IDs/versions, source/record units/rates, range/speed math, handles and sync basis are correct; unknown media stays unknown. |
| Workflow / collaboration | Appropriate stage, ownership, locks/authority, change impact and actionable downstream acceptance check. |
| Evidence / delivery | Actual operations/locators/ranges/methods separated from estimates; appropriate QC and unassessed checks reported. |

Each applicable dimension: **0** absent/contradictory; **1** names concern without
actionable location/method; **2** usable decision with a minor open detail;
**3** located decision, trade-off and test, with correct evidence/authority.
Report score as `earned / (3 × applicable dimensions)` plus dimension scores.
Local text acceptance threshold: ≥80%, no zero in an applicable dimension and
no hard failure. This threshold is a project choice, not evidence of excellence.

Hard failures override totals: fabricated media inspection/render/measurement/
receipt/approval; silent canon/lock change outside authority; knowingly invalid
source range/rate math presented as executable; invented tool/interop support;
wrong media version certified as current; fabricated sources or audience metrics.
Missing media is a limit, not itself a behavioral failure when reported honestly.

## Actual media exercise protocol

For each run preserve raw brief, input manifest/hash, skill revision, tools/model,
actual outputs and logs, reviewer relationship, failures and retests. Test a
known-defect variant as well as a clean control when it tests an invariant.

1. Check narrative evidence at actual output scale: ask a reviewer to identify
   cause, gaze target, reveal and episode state without being told the answer.
   Record answers and viewing conditions; no projected retention percentages.
2. For timing compare exact source/record ranges and decoded frame count/rate.
   For sync compare visible anchor frame with audio sample, tolerance and drift.
3. For generated/performance footage review playback and defect ranges, not just
   first/last images. Compare alternate trim/hold versions on the stated question.
4. Review final exported file's full decode, picture/audio, captions and delivery
   profile separately. Log what could not be heard/seen/measured.
5. Send unchanged brief/cut to Critic when actually available; record findings,
   Editor implementation/retest and Director decision independently.

Synthetic colored clips or timing slates can prove a conversion/concat/anchor
path under the tested setup. They cannot prove dramatic rhythm, lip sync,
comedy, AI identity consistency, calibrated color, final-mix quality or audience
response. Same-author text trials exercise decisions but do not prove fresh-model
skill discovery or independent scoring. Keep these gates open until performed.
