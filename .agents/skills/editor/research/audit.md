## Existing overlap and what Editor adds

Artist already records visual identity/look/assets; Editor references those
versions and reports drift without redefining appearance. Storyteller owns
event truth/knowledge; Editor protects disclosure and implied chronology.
Screenwriter owns performable action/dialogue and estimated script timing;
Editor selects real performances and owns actual record allocation. Cinematographer
owns proposed coverage/action endpoints; Editor tests available joins and requests
missing coverage, without inventing it.

Director already owns vision/creative decisions; Editor adds editorial alternatives,
cut implementation and located version deltas, without taking approval authority.
Critic owns independent findings; Editor preserves their independence while
implementing/retesting selected fixes. Sound Designer already has rational fps,
cut versions, cue/sample anchors and tails; Editor supplies authoritative picture
placement and change lists, retaining audio design/mix ownership. Strategist
remains future/optional; audience claims remain hypotheses without actual data.

The missing integration is **serialization and receiver agreement**, not a reason
to normalize all sibling files. Local timeline proposal and hash-pinned example
make the current assumptions reviewable. No runtime dispatch, new shared API,
additional specialist or external-format exporter is implied.
