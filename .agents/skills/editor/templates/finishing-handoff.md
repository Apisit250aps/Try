# Finishing / delivery packet

- Cut/sequence/version/hash; upstream approval/locks and exceptions.
- Rate/timebase, duration/counting convention/start; source/record mapping.
- Original/proxy manifest, relink mapping; handles; retime/reframe/effects with
  baked/unbaked status; missing/restricted/uninspected media.
- Color input/working/view/output spaces, metadata uncertainties, LUT/CDL versions,
  reference look and responsible colorist; returned-picture comparison.
- Audio reference, guide/master distinction, cue IDs/sample anchors, channels/map,
  sample rate, start, tails/handles, destination-sourced loudness/peak target;
  requested stems and Sound Designer/mixer responsibility.
- Captions language/version/format and significant sound/speaker needs; target
  player/placement, clean/burned-in versions, description/transcript alternative.
- Delivery profile ID/version; actual spec URL/document/version/access date;
  codec/container/raster/PAR/fps/color/range/audio/captions/naming requirements.
- Export: actual tool/version/settings/command/project, input versions, result
  path/hash/log/exit status or **planned only**. Never put a desired path in the
  rendered-artifact field before it exists.
