# Editorial treatment and selects

Use the relevant sections only. A planned selects request is not a viewing log.

- Project / episode / task; treatment ID/version; output language / format.
- Brief, script, canon, look, shot-plan and current-cut IDs/versions/locators.
- Mode: treatment / paper edit / actual assembly; available tools and inspected media.
- Protected facts/beats/reveals; authority/locks; consequential assumptions.
- Intended audience question and emotional progression; actual audience data or hypothesis.
- Editorial approach: perspective, performance/listening emphasis, information order,
  continuity/intentional ruptures, rhythm at scene/sequence/whole-film scale.
- Transitions and audio-image relationship: where, purpose and trade-off.
- Competing option; why selected provisionally; reviewer question/test.
- Timing target and basis; missing coverage/media; change requests and next owner.
