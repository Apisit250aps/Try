# Edit to delivery

Use the stages that match the task. These are local production choices [P16],
not a mandatory universal studio pipeline. See [contract](../references/production-contract.md).

| Stage | Do / produce | Exit question and common failure |
| --- | --- | --- |
| Intent / inventory | Inspect upstream versions/locks, essential actions, source availability, tools and destination. Draft editorial treatment. | Are constraints/unknowns explicit? A named clip is not an inspected file. |
| Ingest / proxies | Preserve originals, manifest/relink mapping; verify readable media and synced proxies if needed. | Do proxies correspond to the right originals and channels? Duplicate filenames alone are unsafe identity. |
| Selects | Review takes, log usable ranges and performance turns, defects, coverage and handles. | Can each required beat be realized? Do not equate longest/cleanest take with strongest performance. |
| Assembly / paper edit | Build causal information order; include explicit missing-media slates only in labeled review versions. | Can the action be understood? Do not polish a missing setup away. |
| Rough cut | Test structure, perspective, scene turns and whole-film rhythm; compare focused alternatives. | Does moving a scene change knowledge/canon? Request that change if outside authority. |
| Fine cut | Refine shot/beat duration, reactions, J/L, action/eyeline joins and transitions; update provisional audio anchors. | Do trims preserve meaning and actual sync? Avoid frames-only reasoning without playback. |
| Review / final editorial cut | Located notes with expected/observed, severity/confidence; implement accepted changes and retest affected ranges/context. | Which notes are verified, declined or awaiting evidence? A self-review is not Critic acceptance. |
| Picture lock | Freeze exact cut/version/hash, timebase/duration, authority/scope and exceptions. | Is the approval real? Picture lock is not final-mix/export approval. |
| Conform / online | Relink originals; carry or bake supported effects, retimes, grades and captions; compare against reference. | Did interchange preserve intended picture/sync? A parsed XML is insufficient. |
| Color / sound / accessibility | Supply locked reference, source map, handles, channel/transform/anchor notes; verify returned cut IDs and changes. | Are returned elements actually for this cut? Don't overwrite Sound Designer's mix as an editorial shortcut. |
| Finishing / export / QC | Apply verified profile; render with logs; inspect delivered file and record acceptance scope. | Was the whole file decoded and picture/audio reviewed? Export success is not release permission. |

## Revise selectively

Receive note CR-07 on CUT-03 v2. Locate the original event/beat; reproduce the
problem at the evidence level available. If Critic and Director disagree,
preserve the independent finding and log the Director's disposition. Do not
change a score to manufacture agreement.

Map the smallest effective fix: trim/extend, slip/roll, alternate performance,
reorder, new coverage or regeneration. Slip changes source selection within a
record allocation; ripple changes later positions; roll redistributes adjacent
duration. None is automatically harmless to narrative or audio. Check locks,
available media/handles and sync before execution. For a locked/out-of-scope
change provide old/new plan, cost, affected owners and acceptance test; implement
once authorized, without repeatedly asking about an already granted change.

New cut version → explicit event/media delta → downstream invalidation by timing
and content → changed-range tests → joins/context/full-export checks as needed.
Do not regenerate approved scenes unrelated to the defect. Carry previous valid
results only when the artifact/range and dependencies are demonstrably unchanged.

## Standalone / blocked path

No media: return treatment and paper edit, use null source availability and
estimated durations. No renderer: return real timeline metadata and a labeled
handoff, not an MP4 claim. No Sound Designer: keep temp/guide audio labeled,
specify cue/sync needs and pending mix. No previous episode: leave continuity
certification open. Unknown export destination: propose a local review profile
and request the actual specification only before dependent final delivery.

Do useful unaffected work. Block a source-dependent claim precisely; don't
invent a complete project or launch missing specialists to fill the gap.
