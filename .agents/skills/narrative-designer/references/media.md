# Medium, production and release

Identify actual platform, locale, account, feature and date; do not assume TikTok,
Shorts or Reels can route per-viewer choices or persist state. Verify capability
before committing to an interaction. If unknown, label unverified and design a
manual navigable set with clear route IDs, discoverable links where supported,
fallback search/naming, recap and standalone episode context. A viewer vote is a
group editorial decision with deadline, eligibility, tie rule and publication
schedule; it does not choose a separate path per viewer. Preproduced A/B clips can
coexist without interaction. A genuinely interactive player needs an actual runtime,
input handling, state persistence, accessibility and testing, none supplied here.
Work with Strategist on discovery, navigation and release order, and Director and
specialists on feasibility. Do not claim a platform test or publish anything.

For 30–60s clips estimate each cut's duration including transitions, context and
choice instruction; an audience path spanning clips is longer. For long-form,
series, games or visual novels adapt the granularity, route memory and production
plan. Story time is the fictional interval, not runtime. Track shared vs alternate
scenes/clips, footage, sound, animation, edit and QA effort; estimate total unique
production and route playback separately. Confirm timing by a real timed animatic or
cut; prose estimates do not prove runtime.
