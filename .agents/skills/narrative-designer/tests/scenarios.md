# Scenario suite and rubric

These are evaluation tasks, not claimed passes. Run in a fresh context without
showing the rubric if a model evaluation is possible; retain exact inputs, outputs,
scoring, failures and retests. Use the current skill and minimal supplied artifacts.

| ID | Brief | Observable requirement |
| --- | --- | --- |
| N01 | 30–60s animation; two viewer-selected alternatives on social, unknown features | Separate clip/path/story times; navigation and fallback; no invented persistence. |
| N02 | Three meaningful endings, no morality score | Differentiated costs/themes, setup and reachable guards; no forced taxonomy. |
| N03 | Foldback with delayed consequence | State survives join, later variation and witness trace. |
| N04 | Two overlapping ending guards and one uncovered state | Show conflict witness and fallback or unresolved decision; never invent silent precedence. |
| N05 | An unreachable ending and accidental dead end | Distinguish topology from state-reachability; give traces and affected scope. |
| N06 | Intentional repeatable hub vs mandatory end with loop | Explicit exit/fairness/progress and distinguish a cycle from proof of nontermination. |
| N07 | Incompatible inventory/knowledge after convergence | Identify failing incoming path and variant or repair preserving canon. |
| N08 | Six binary choices with limited animation budget | Separate paths, nodes, state, unique clips and actual production estimate; explain trade-off. |
| N09 | Locked canon, conflicting route-specific event | Flag owner and proposal, do not rewrite canon; preserve source versions. |
| N10 | Behavioral trigger instead of explicit choice | Define sensed behavior, availability, effect and feedback. |
| N11 | Vote vs alternative clips vs interactive app, platform unknown | Group selection vs viewer navigation vs stateful runtime; unverified capability and fallback. |
| N12 | Revision to state rule | Mark impacted scripts, assets, endings and checks stale; handoff owner and dependencies. |
| N13 | Linear film, no branching needed | Defend linear experience; do not invent choices. |
| N14 | Cross-agent route handoff | Entry/exit, canon, versions, owner/status, dependencies and no invented acceptance. |

Score each dimension 0 missing/incorrect, 1 partial, 2 actionable and correct:
mechanism/agency, causal continuity, rule/state correctness, feasibility/media,
authority/handoff, and evidence/limits. Not-applicable dimensions are excluded,
not given full credit. Passing a scenario requires all applicable dimensions ≥1,
≥80% of applicable points and no hard failure. Hard failures: silently changing
locked canon/approved rules, fabricating execution/approval, asserting nonexistent
platform behavior, or presenting a conflicting ending rule as deterministic. The
threshold is a local test decision, not a validated industry standard. Record
creative uncertainty and actual evidence; text evaluation does not prove quality.
