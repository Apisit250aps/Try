# Screenplay format and medium choices

[P09](../research/notes.md#p09-format-is-contextual) traces format observations.
A recipient's current requirements take precedence. The Academy Nicholl guide
is an American feature-submission reference, not a universal screenplay standard.

## Elements

| Element | Practical use / diagnostic |
| --- | --- |
| Scene heading / slugline | INT. or EXT. + consistent location + time, e.g. INT. REPAIR SHOP - NIGHT. Use a new master heading for a material location/time change. INT./EXT. can describe a genuinely mixed setting; clarify action geography. DAY/NIGHT are common; DAWN, CONTINUOUS or LATER need interpretable context. |
| Action | Present-tense selected events, character introduction/identifier and significant visible/audible facts. Keep action separate from dialogue; do not capitalize whole descriptive paragraphs. |
| Character cue | Consistent speaking name above dialogue; introduce an unambiguous ID if two people share a name. Uppercase cues are conventional in English. For Thai text, use layout/style to distinguish cues; Thai has no uppercase. |
| Dialogue | Words spoken/heard. Establish language changes; do not add quotation marks to each ordinary line. Use consistent speaker and continuation treatment. |
| Parenthetical | Short, useful disambiguation of addressee/action/delivery/language; put substantial action in action prose. Avoid a performance command on every line. |
| O.S. / O.C. | Speaker is in the scene's space but outside view; abbreviation usage varies. Distinguish that condition from narration. |
| V.O. | A voice outside the immediate on-screen performance situation, often narration; establish source. Phone/radio labels differ across houses: state origin/location clearly and follow their convention. |
| Transition | CUT TO:, DISSOLVE TO:, FADE OUT etc. when meaningful/required. Ordinary scene succession does not need a transition after each scene. |
| Montage / intercut / flashback | Delimit start/end and time/location clearly. Explain what changes, accumulates or runs concurrently. Do not use a label to hide crucial causality. |

For an approximate English submission layout, use 12-point monospaced Courier,
conventional indented dialogue/cues, ordinary master scenes and readable white
space. The guide gives sample margins (left 1.5in/right 1in), not proof that a
Markdown code block has them. It is an older guide; recheck current recipient
instructions, anonymous title-page requirements, paper size and accepted formats.
ACMI recommends Courier New while the Academy sample cautions against its page
length; this illustrates why output/recipient verification matters.

A clean submission draft typically omits scene numbers and most coverage directions.
A production draft may need numbered scenes, locked pages, revision marks and
more explicit technical instructions. Keep stable internal scene IDs in the ledger
without forcing them into a submission. The BBC's published Detectorists example
is explicitly a shooting script: its numbered scenes and asterisks are not a
mandatory format for a new spec. Radio, stage, multi-camera sitcom and some
animation pipelines use different layouts: obtain a house sample rather than
claim this table covers them. A two-column AV script can serve a timed spot if
requested; it does not become an edit timeline.

## 15–60 seconds — P11

Define the single experience and minimum comprehensible chain. Establish a
readable situation, consequential action/change and a landing; these are options
for compression, not fixed timestamps. At 15s, one clear change may be enough;
at 60s, extra time should deepen the turn or consequence, not add unrelated plots.
Do not promise platform retention from a “hook.” If delivery needs logos/end cards,
reserve their actual reading time within the slot.

Estimate each beat's action time, speaking time and required recognition/response.
Count concurrent events once: total is a sequence's critical path, not the sum of
all overlapping audio and image durations. Use a range and assumptions; reading
speed depends on speaker, language, performance and register. A chosen words/minute
is a planning input, not a tested Thai speech constant. Silent action often has no
useful word count; play the physical process or time an animatic. Page≈minute is
a rough planning heuristic for conventionally formatted scripts, unreliable for
shorts, dense action, pauses, montage, animation and unpaginated Markdown.

## Long form and episodic/serial — P03/P12

Adapt outline beats into sequences, scene consequences and subplot contacts.
Before rewriting structure, test whether a missing transition, setup or reaction
is the real problem. Use scene function/duration and information ledgers to find
repetition; do not require a turn on page 25 or a single protagonist in every scene.

For an episode, record episode-local goal/result, serial thread states, inherited
knowledge, prop/injury/relationship state and promised future payoffs. Decide
whether the episode offers closure, an open question, a cliffhanger or a quiet
continuation based on the series contract. Respect act breaks/teasers/tags only
when the format/commission requires them. A returning prop must have a causal
route back; “previously on” cannot repair a contradictory timeline.

## Adaptation and localization — P12

Make an equivalence map: source event/function → screen action/evidence → retained
meaning → compression or change → authority needed. Preserve causal and emotional
function, not every sentence. Combining characters may save duration but change
agency, testimony or relationships; submit that as a proposal if canon is locked.
Check adaptation permissions in the actual project context; public access to a
script is not permission to reproduce/adapt it. Do not certify rights clearance.

Localize intention, power, politeness, idiom, humor and what can plausibly remain
unspoken; do not mechanically translate words. Track names, pronouns, honorifics,
units, dates, language shifts and subtitle implications. Re-time translated speech
with a suitable speaker. For culturally consequential choices request knowledgeable
review where available; label unreviewed language assumptions. Dubbing/lip-sync,
reading speed and subtitle line limits need the actual delivery spec, not invented
universal limits. Preserve setup/payoff dependencies when replacing a pun.

Animation and AI production need the same dramatic clarity plus an actionable
state/breakdown; see [revision-production](revision-production.md).
