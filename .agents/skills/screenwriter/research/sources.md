# Source registry — Screenwriter

Access date for every entry: **2026-11-25 (Asia/Bangkok)**. These are actual web
opens and inspected text sections, not a bibliography of books claimed as read.
PDF locators distinguish PDF page index (1-based here, including cover) from
printed screenplay pages. No external screenplay/text is redistributed. A working
URL is not a reuse license. Public access is verified for the inspected response,
not guaranteed permanently. HTML/PDF text extraction is not a full video viewing.

Classes: **C** institution/recipient convention; **E** expert/practitioner position;
**O** observation of a published artifact; **G** scoped organizational guidance;
**H** local craft heuristic; **D** The Stories design proposal. No source here is
an experimental demonstration of the skill's quality. H/D are not external standards.
