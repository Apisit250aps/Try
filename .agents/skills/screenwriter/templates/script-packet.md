# Script packet — use only relevant sections

Project/task; mode; script version/date/status; medium/language/house format;
upstream bible/outline versions and IDs; owner/approval evidence or pending;
duration target; locked facts; provisional assumptions; available resources;
source/adaptation status if applicable.

## Script

Insert the actual screenplay in the requested format. Keep analysis out of it.
Record the artifact path when a file exists; don't invent a PDF/FDX export.

## Scene and beat ledger

This is the master script ledger. Do not maintain duplicate versions of the same
facts in a separate beat sheet unless the receiver needs an exported view.

For short timed work, add beat start/end **planned** windows and note overlapping
action/audio. Distinguish planned slot allocation from plausible estimate and measured
read/animatic duration. List any speaking-rate assumptions and unmeasured holds.

## Delivery check

Actual artifacts; supplied vs invented facts; source/continuity coverage; performed
checks and method; unresolved decisions with owner; next useful test. Use draft,
reviewed, approved, estimated, measured and handoff-accepted accurately.
