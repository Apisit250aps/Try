# S01 — เรือเที่ยวสุดท้าย / บทร่าง v1

แอนิเมชันภาษาไทย 30 วินาที งานต้นฉบับในโหมด standalone; สมมติฐานชั่วคราว: หุ่นยนต์ตัวเล็กมีนิสัยเก็บทุกอย่างให้เป็นระเบียบ เรือกระดาษมีรอยฉีกที่กราบอยู่แล้ว ทั้งเรื่องอยู่ในห้องเดียว ฝนเห็นผ่านหน้าต่าง ไม่มีเสียงใดทั้งสิ้น รวมเสียงฝน เสียงกลไก ดนตรี บทพูด VO และข้อความอ่านได้

## บท

**INT. ห้องเล็ก — กลางวัน**

ฝนไหลเป็นสายอยู่นอกหน้าต่าง ใต้รอยรั่วมีแอ่งน้ำเล็ก ๆ

หุ่นยนต์ตัวเล็กใช้ผ้าซับน้ำ ดันผ้าเป็นเส้นตรง เก็บขอบแอ่งจนเรียบ

เรือกระดาษลอยอยู่ตรงส่วนที่ยังไม่เช็ด กราบข้างหนึ่งฉีก น้ำซึมเข้า เรือเอียง

หุ่นยนต์ยกเรือขึ้น น้ำหยดลงบนพื้นแห้ง มันมองหยดน้ำ แล้วมองถังขยะข้างตัว

มันยื่นเรือเหนือปากถัง มือเปิดออกนิดหนึ่ง

เงาเรือไหวบนฝ่ามือของมัน

หุ่นยนต์หุบมือกลับ ย่อตัวลงที่แอ่งน้ำ

มันรองท้องเรือด้วยสองฝ่ามือ ยอมให้แขนเปียก แล้วเลื่อนมือไปตามขอบแอ่ง เรือเคลื่อนไปข้างหน้าอย่างไม่เอียง

ปลายกราบที่ฉีกยังห้อยอยู่เหนือน้ำ หุ่นยนต์เลี้ยวเรืออ้อมผ้าซับที่วางขวางทาง ราวกับอ้อมเกาะ

ถึงปลายแอ่ง มันไม่ยกเรือทิ้ง แต่หมุนสองฝ่ามือ พาเรือออกเที่ยวกลับ

## บีตและเวลา

| บีต | หน้าที่ / หน้าต่างจัดสรร |
| --- | --- |
| B01 | ตั้งนิสัยเก็บกวาดและภูมิศาสตร์ฝน–รอยรั่ว–แอ่ง 0–6 วินาที |
| B02 | เรือรั่วขัดจังหวะงาน; ยกแล้วทำพื้นเปียกอีก 6–12 วินาที |
| B03 | เกือบทิ้ง ก่อนเลือกเก็บไว้ 12–18 วินาที |
| B04 | เปลี่ยนมือจากเครื่องมือเก็บกวาดเป็นสิ่งรองรับการเล่น; เที่ยวกลับยืนยันการเลือก 18–30 วินาที |

การเปลี่ยนความเข้าใจเกิดจากมือที่เกือบปล่อยเรือลงถัง กลับยอมทำงานเก็บกวาดค้างไว้เพื่อเล่นกับของชำรุด เรือไม่ได้กลับมาลอยเอง ไม่มีการปิดรอยฉีกหรือซ่อมสำเร็จ

จัดสรรเป้าหมาย 30 วินาที; ประเมินการแสดงจริงราว 28–35 วินาที โดยสมมติว่าการเลื่อนเรือเป็นการเคลื่อนไหวต่อเนื่องครั้งสั้น ๆ ยังไม่มีการอ่านจับเวลา แอนิแมติก หรือทดสอบผู้ชม หากเกินเวลา ให้ลดระยะเดินทาง ไม่ตัดจังหวะถอนมือจากถัง

## ส่งต่อการผลิต — เตรียมไว้ ยังไม่มีผู้รับยืนยัน

- Artist: หนึ่งหุ่นยนต์ หนึ่งห้อง เรือหนึ่งลำ ผ้า ถังขยะ หน้าต่างและแอ่งน้ำ รอยฉีกต้องอยู่ข้างเดิมและเห็นได้ทั้งก่อนกับหลัง ฝ่ามือรองใต้เรือ ไม่จับกราบจนดูเหมือนซ่อม
- Cinematographer: ต้องอ่านลำดับเรือรั่ว → ปากถัง → มือหุบกลับ → มือรองเรือได้ ขอคืนข้อจำกัดหากภูมิศาสตร์ทำให้เข้าใจว่าเรืออยู่นอกห้อง; ไม่ได้กำหนดช็อตหรือกล้อง
- Editor: รักษาการเกือบปล่อยและเที่ยวกลับซึ่งยืนยันว่าการเก็บเรือเป็นความตั้งใจ เวลาข้างต้นเป็นเวลาบท ไม่ใช่ไทม์ไลน์
- Sound Designer: เวอร์ชันหลักเงียบสนิท ไม่มีเสียงฝนแม้เห็นฝน
- การเข้าถึง: เตรียมคำบรรยายภาพแยกสำหรับเวอร์ชันเข้าถึง โดยเผยการเปลี่ยนมือเมื่อมันเกิดขึ้น ไม่เติมเสียงหรือข้อความในเวอร์ชันหลัก
