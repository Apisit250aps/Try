# S02 — อีกกล่อง / บทร่าง v1

ฉากต้นฉบับภาษาไทย เป้าหมายต่ำกว่า 90 วินาที สมมติฐานชั่วคราว: พี่น้องผู้ใหญ่สามคนกำลังเก็บร้านของพ่อที่เลิกกิจการ พิมเป็นพี่คนโต ต้นกำลังจะกลับ เมย์ช่วยเก็บและไม่พูดตลอดฉาก ไม่กำหนดเหตุที่ร้านปิดหรือสถานะของพ่อเพิ่มเติม

## บท

**INT. ร้านของพ่อ — เย็น**

ชั้นวางเกือบว่าง พิมห่อถ้วยใบสุดท้าย ต้นสวมกระเป๋าสะพาย เมย์พับลังอยู่ระหว่างทั้งสอง

**พิม**  
กล่องนั้นยังปิดไม่ได้

ต้นวางมือลงบนฝากล่อง

**ต้น**  
มีอะไรอีก

พิมหยิบถ้วยที่ห่อแล้วขึ้นมา แล้ววางกลับที่เดิม

**พิม**  
ต้องมีคนประคอง ตอนผูกเชือก

ต้นถอดกระเป๋า ย่อตัวกดฝากล่อง พิมพันเชือกรอบกล่องช้า ๆ

**ต้น**  
ผมจับอยู่

**พิม**  
รู้แล้ว

เธอผูกปม เสร็จแล้วแต่ยังจับปลายเชือกไว้

เมย์เลื่อนลังเปล่าอีกใบมาให้ เปิดก้นลังที่สอดล็อกไว้เรียบร้อยแล้ว จากนั้นยกกล่องที่ต้นประคองอยู่ไปวางกับกองเสร็จ

ต้นลุกขึ้น หยิบกระเป๋า

**ต้น**  
หมดแล้วนะ

พิมมองลังเปล่า

**พิม**  
พรุ่งนี้ชั้นบนก็ต้องเก็บ

**ต้น**  
พรุ่งนี้ค่อยส่งมาว่าให้ทำอะไร

ต้นสอดแขนเข้าหูกระเป๋า เมย์ยกเก้าอี้พับสองตัวที่เหลืออยู่ ตัวหนึ่งวางหลังพิม อีกตัวลากผ่านต้นไปทางประตู

พิมก้าวขวางเก้าอี้ตัวที่สองไว้

**พิม**  
ตัวนี้เอาไว้ก่อน

เมย์ปล่อยเก้าอี้ พิมกางมันข้างลังเปล่า

**พิม**  
จะสั่งข้าว นายเอาอะไร

ต้นจับหูกระเป๋าค้าง

**ต้น**  
สั่งเผื่อได้ กับอยากให้กินด้วย มันคนละอย่างนะ

พิมปล่อยเชือกในมือ วางโทรศัพท์ลงโดยยังไม่โทร

**พิม**  
กินด้วยกันก่อนสิ

ต้นถอดกระเป๋า วางบนเก้าอี้

**ต้น**  
งั้นผมสั่ง พี่ห่อถ้วยสองรอบแล้ว

พิมหยุดมือ มองถ้วยบนกล่อง เมย์เลื่อนลังเปล่าออกจากหว่างพี่น้อง แล้วนั่งลงบนกล่องที่ปิดเสร็จ

## บีต / เวลาโดยประมาณ

1. พิมใช้การผูกกล่องยืดเวลา; ต้นช่วยเฉพาะงานที่ขอ — 0–21 วินาที
2. เมย์เอางานที่เสร็จออก ทำให้ข้ออ้างแรกใช้ต่อไม่ได้ — 21–31 วินาที
3. พิมโยนงานวันพรุ่งนี้ ต้นส่งเรื่องกลับไปเป็นข้อความ; การเอาเก้าอี้ออกทำให้ต้องเลือกเดี๋ยวนี้ — 31–50 วินาที
4. ข้าวกลายเป็นข้ออ้างสุดท้าย ต้นขอให้ระบุความต้องการ พิมเชิญจริง ต้นอยู่ — 50–78 วินาที

ช่วงสมเหตุผลราว 72–87 วินาที ประเมินจากประโยคสั้นกับงานมือที่ทำพร้อมคำพูด จังหวะรอสามแห่งยังไม่จับเวลาจริง หากยาวเกิน ให้กระชับการผูกเชือกก่อนลดความเงียบหลังคำว่า “คนละอย่าง”

## วินิจฉัยเสียงและนัย

พิมพูดเป็นงานหรือของใช้: กล่อง ชั้น เก้าอี้ ข้าว การเก็บเก้าอี้จึงเผยความต้องการก่อนคำเชิญ ต้นตอบให้ชัดว่าหน้าที่จบเมื่อไร ใช้ประโยคเต็มขึ้นเมื่อข้ออ้างไม่พอ และอยู่หลังได้รับคำเชิญที่เรียกเขาเข้าร่วมจริง

เมย์ไม่ใช่เพียงพยาน: การเอากล่องเสร็จไปและเกือบยกเก้าอี้ออก ถอนเครื่องมือยื้อของพิม จนพิมต้องเปลี่ยนวิธี ไม่มีบรรทัดอธิบายประวัติครอบครัว การวินิจฉัยนี้เป็นการอ่านบทเอง ยังไม่มีนักแสดงหรือผู้ฟังทดสอบเสียงตัวละคร
