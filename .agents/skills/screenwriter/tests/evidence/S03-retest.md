# ที่แห้ง

บทต้นฉบับภาษาไทย — ฉบับร่าง 1

สมมติฐานสำหรับงานเดี่ยว: หนังสั้นปริศนาในบ้าน เจ้าของเหรียญคือชาญ อดีตนักกีฬา; อิงเป็นลูกสาว และเมย์เป็นผู้ช่วยจัดของก่อนงานแสดงเล็ก ๆ ในบ้าน ชื่อ ความสัมพันธ์ และสถานที่เป็นรายละเอียดที่เสนอขึ้นใหม่ ข้อเท็จจริงที่ยึดตามโจทย์: ชาญย้ายเหรียญเพื่อป้องกันความเสียหาย ไม่มีการขโมย และเมย์บริสุทธิ์

## บทภาพยนตร์

### ภายใน — ห้องรับแขกบ้านชาญ — กลางวัน

ฝนกระทบหน้าต่าง

เมย์วางกระเป๋าผ้าข้างเท้า เปิดฝากล่องแสดงเหรียญบนโต๊ะ

ช่องกำมะหยี่รูปวงกลมว่างเปล่า

อิงหยุดจัดเก้าอี้ มองช่องนั้น แล้วมองกระเป๋าเมย์

**อิง**  
เมื่อเช้ายังอยู่

เมย์ยกกล่องขึ้น ใต้กล่องเป็นรอยน้ำ บนโต๊ะมีหยดใหม่ตกลงมา

เหนือโต๊ะ ฝ้าเพดานเป็นวงชื้น บนชั้นสูงข้างผนังมีกล่องขนมเหล็กปิดฝา ชายผ้าเช็ดหน้าลายตารางโผล่พ้นขอบฝา

เมย์เลื่อนกล่องแสดงเหรียญพ้นจุดน้ำหยด

**เมย์**  
ลุงชาญอยู่ไหนคะ

**อิง**  
ซ่อมรางน้ำ เธอเข้ามาคนเดียวใช่ไหม

เมย์มองอิง อิงยังมองกระเป๋า

เมย์หยิบกระเป๋าขึ้น เทของลงบนเก้าอี้: สมุด ปากกา กล่องข้าว ร่มพับ

เธอแบะปากกระเป๋าว่างให้อิงดู

อิงไม่รับมันไว้

**อิง**  
ฉันยังไม่ได้บอกว่า—

เสียงขาบันไดครูดพื้นดังจากนอกบ้าน

เมย์เก็บของใส่กระเป๋าทีละชิ้น แล้วเดินออกไป

### ภายนอก — ชานบ้าน — ต่อเนื่อง

ชาญลงจากบันได มือหนึ่งหิ้วถังเครื่องมือ เสื้อเปียกฝน

บันไดโยก เมย์วางกระเป๋าแล้วจับขาไว้ให้

ชาญลงถึงพื้น ยิ้มให้เมย์ เธอหลบตา

อิงปรากฏที่ประตู ถือกล่องแสดงเหรียญว่าง

**อิง**  
พ่อ เหรียญหาย

ชาญมองกล่อง แล้วมองขึ้นไปทางเพดานในห้อง เขาหิ้วถังเดินผ่านอิงเข้าไป

### ภายใน — ห้องรับแขกบ้านชาญ — ต่อเนื่อง

ชาญวางถังเครื่องมือใต้รอยรั่ว

ติ๋ง

เขาเอื้อมหยิบกล่องขนมจากชั้นสูง เปิดฝา ดึงผ้าเช็ดหน้าลายตารางออกมา

เมย์กับอิงยืนที่ประตู

ชาญคลี่ผ้า เหรียญอยู่กลางผ้า สายคล้องพับไว้อย่างเรียบร้อย เขาพลิกเหรียญตรวจทั้งสองด้าน ใช้นิ้วแตะผ้าแห้ง

เขาจะวางเหรียญคืนกล่องแสดง อิงยื่นกล่องให้

หยดน้ำอีกหยดตกลงในถัง

ชาญชะงัก ห่อเหรียญกลับในผ้า ปิดไว้ในกล่องขนม แล้วยกกลับขึ้นชั้นสูง

อิงค่อย ๆ ลดกล่องแสดงลง

เธอหันไปหาเมย์

**อิง**  
ขอโทษ

เมย์มองอิงอยู่ครู่หนึ่ง ก่อนยื่นมือรับกล่องแสดงเหรียญ

**เมย์**  
ตรงโน้นแห้งค่ะ

เธอชี้โต๊ะอีกฝั่ง อิงยกเก้าอี้หลบทางให้

## บันทึกความรู้และการเปลี่ยนจังหวะ

ชาญรู้ตลอดว่าเขาห่อเหรียญแล้วย้ายขึ้นที่แห้ง ก่อนเหตุการณ์ในบท; เขาอยู่นอกห้องระหว่างการกล่าวหา จึงไม่ได้ยินและไม่ได้ร่วมสงสัยเมย์

| จังหวะ / ฉาก | ผู้ชมรู้หรืออนุมานได้ | เมย์รู้หรือเชื่อ | อิงรู้หรือเชื่อ |
| --- | --- | --- | --- |
| B01 / ห้องรับแขกครั้งแรก: พบช่องว่าง | เหรียญไม่อยู่ที่เดิม ยังไม่รู้ว่าใครย้ายหรือเพราะอะไร | เพิ่งพบว่าเหรียญหายจากกล่อง ไม่ได้เป็นผู้เอาไป | เคยเห็นเหรียญเมื่อเช้า เริ่มสงสัยเมย์ |
| B02 / ห้องรับแขกครั้งแรก: น้ำและกล่องขนม | มีน้ำรั่วจริง; มีกล่องปิดฝาอยู่พ้นน้ำ แต่ยังไม่เห็นของข้างใน | เห็นเหตุให้นำของออกจากจุดนี้ ยังไม่รู้ที่อยู่ของเหรียญ | มุ่งที่กระเป๋าเมย์ ไม่ได้ตรวจกล่องขนม |
| B03 / กระเป๋าว่างและชานบ้าน | กระเป๋าที่ตรวจไม่มีเหรียญ; ชาญกำลังซ่อมปัญหาน้ำจริง แต่ยังไม่ยืนยันผู้ย้าย | รู้ว่าตนถูกสงสัย ยังไม่รู้คำตอบ | ความสงสัยไม่มีหลักฐานจากกระเป๋า แต่ยังไม่รู้ว่าเหรียญอยู่ไหน |
| B04 / ห้องรับแขกครั้งหลัง: ชาญเปิดกล่อง | ชาญรู้ตำแหน่งและวิธีเก็บ; เหรียญถูกห่อไว้ในที่แห้ง การห่อกลับเมื่อได้ยินน้ำหยดเผยเจตนาป้องกันน้ำ | เห็นคำตอบพร้อมผู้ชม ชาญเป็นผู้เก็บรักษาเหรียญ | เห็นว่าการย้ายคือการปกป้อง มิใช่การขโมย และตนกล่าวหาเมย์ผิด |
| B05 / คำขอโทษและย้ายโต๊ะ | ความจริงเปลี่ยนการปฏิบัติต่อเมย์; ทั้งคู่เริ่มทำงานร่วมกันอีกครั้ง | ได้รับคำขอโทษ เลือกช่วยจัดที่แห้งต่อ | ยอมรับผิดและช่วยเมย์โดยเปิดทาง |

## Setup / payoff ที่ต้องรักษา

| Setup ก่อนเฉลย | ความหมายเมื่อพบครั้งแรก | Payoff |
| --- | --- | --- |
| รอยน้ำใต้กล่องแสดงและหยดจากฝ้า ใน B02 | สภาพห้องและปัญหาที่เมย์ต้องแก้เฉพาะหน้า | ใน B04 ชาญตั้งถังรับน้ำ และห่อเหรียญกลับแทนการคืนจุดเสี่ยง แสดงเหตุผลของการย้ายด้วยการกระทำ |
| กล่องขนมบนชั้นสูง มีชายผ้าตารางพ้นฝา ใน B02 | ของใช้ในบ้านที่อยู่พ้นน้ำ ยังไม่เปิดเผยว่าเก็บอะไร | ชาญหยิบกล่องใบเดิมและคลี่ผ้าผืนเดิมใน B04 เหรียญไม่ได้ปรากฏจากภาชนะหรืออุปกรณ์ที่เพิ่งเพิ่มตอนจบ |
| ชาญซ่อมรางน้ำตามคำตอบของอิง และลงจากบันไดพร้อมเครื่องมือใน B03 | เจ้าของอยู่ระหว่างแก้ปัญหาน้ำ | สนับสนุนว่าการเก็บเหรียญในที่แห้งเป็นการป้องกันของของตน ไม่ใช่การปกปิดการขโมย |
| เมย์เทกระเป๋า แต่อิงไม่รับกระเป๋าที่เธอยื่น ใน B03 | การตรวจไม่ได้คืนความไว้วางใจ | ใน B05 อิงยอมส่งกล่องแสดงให้เมย์และช่วยเปิดพื้นที่ เป็นผลของการยอมรับผิด |

## ระยะเวลาและสถานะ

ประมาณ **85–110 วินาที**: ห้องรับแขกครั้งแรก 35–45 วินาที; ชานบ้าน 15–20 วินาที; กลับเข้าห้องและปิดเรื่อง 35–45 วินาที ประเมินจากการเคลื่อนของ การเทและเก็บกระเป๋า การเปิด–ห่อเหรียญ บทพูดสั้น และเวลารับรู้หลักฐาน โดยนับบทพูดกับการกระทำที่ซ้อนกันเพียงครั้งเดียว รวมการเปลี่ยนฉากต่อเนื่องแล้ว

เป็นการประมาณจากข้อความ ยังไม่ได้อ่านจับเวลา แสดงซ้อม หรือทำแอนิเมติก ต้องให้ผู้ชมเห็นรอยน้ำ กล่องขนม และชายผ้าก่อนเฉลย รวมทั้งเห็นการห่อเหรียญกลับชัดเจน ข้อความนี้เป็นบทและบันทึกส่งต่อที่เตรียมไว้ ยังไม่มีการอนุมัติหรือทดสอบกับผู้ชม
