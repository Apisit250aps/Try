- ผลงาน: `S04.md` เป็นคำตอบฉบับสมบูรณ์และบทฉบับร่าง 1 สถานการณ์และตัวละครคิดขึ้นสำหรับงานนี้ ไม่มีเรื่องเดิมหรือแคนนอนที่ผู้ใช้ส่งมา

อ่านข้อแนะนำการเขียนและตัวอย่างใน runtime เพื่อจัดเหตุและผล การแสดงที่ไม่มีบทพูด และแยกเวลาจัดสรรจากเวลาที่สังเกตจริง ไม่ได้ดัดแปลงตัวอย่างเหล่านั้นเป็นบทนี้ ผลรวมการอ่านเอกสารผ่านเครื่องมือมีการตัดทอนข้อความบางส่วนในคำตอบที่แสดง โดยส่วนที่ปรากฏมีคำแนะนำเรื่องเวลาและตลกที่ใช้กับงานนี้

## เครื่องมือที่ใช้จริง

- `functions.exec` เรียก `tools.exec_command` เพื่ออ่านไฟล์ด้วย `cat` สร้างโฟลเดอร์ outputs ด้วย `mkdir -p` และตรวจว่าไฟล์ผลงานทั้งสองมีอยู่ด้วย `ls -l`
- `Promise.allSettled` ใช้อ่าน runtime references และ template ที่เป็นอิสระต่อกันในคราวเดียว
- `tools.apply_patch` เขียน `S04.md` และ `run.md` ภายในโฟลเดอร์ที่ได้รับมอบหมาย

ไม่ได้ใช้เครือข่าย ไม่อ่าน `research/`, `tests/`, งานทดลองอื่น หรือบทสนทนาอื่น ไม่สร้างภาพ วิดีโอ หรือเสียง และไม่ติดต่อเอเจนต์อื่น

## ขอบเขตหลักฐานและข้อจำกัด

- ตรวจความสอดคล้องจากข้อความระหว่างการร่าง: การเร่งและหมุนพัดลมที่ตัวละครเลือกทำเป็นเหตุให้กระดาษปลิว อุปกรณ์สำคัญปรากฏตั้งแต่ต้น การแก้สถานการณ์และภาพจบใช้ของเดิม
- เวลาที่ระบุเป็นการประมาณจากลำดับการกระทำ ไม่ได้ใช้การอ่านออกเสียง การซ้อม การจับเวลาแอนิเมติก หรือฟุตเทจจริง ช่วงเวลา 42–52 วินาทีเป็นช่วงประมาณของผู้เขียน ไม่ใช่ผลวัด
- ความแรงลม น้ำหนักกระดาษ และตำแหน่งถังต้องทดลองจริง กลไกนี้ยังไม่ผ่านการทดสอบอุปกรณ์
- ไม่มีผู้ชมทดลอง ไม่มีการวัดเสียงหัวเราะ ไม่มีคะแนนตนเองหรือคำอ้างว่าได้รับอนุมัติ
