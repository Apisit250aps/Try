# S06 — อีกด้านของบาน / E02 opening v1

ต้นทาง: สถานะจบ E01 และคำสั่ง outline E02 ที่ให้มา ไม่มีบท E01 ฉบับเต็มให้ตรวจ สถานะ: บทร่างเปิดตอนที่เล่นได้ถึงขอบข้อจำกัด; การเข้าห้องและการคืนดีสมบูรณ์ยังต้องมีคำตัดสินเจ้าของเรื่อง

ล็อก: กุญแจเพียงดอกเดียวหักอยู่ในประตูห้องช่าง น้อยอยู่นอกห้อง ไม่รู้ว่าพี่อยู่ข้างใน พี่พูดไม่ได้ หน้าต่างเล็กเกินคนผ่าน แต่ส่งของได้ สมมติฐานจัดฉากชั่วคราว: หน้าต่างมีช่องเปิดอยู่แล้ว และมีพื้นให้ทั้งคู่ยืนถึงช่องจากคนละฝั่ง ไม่สมมติทักษะสะเดาะกุญแจ

## บท

**EXT. หน้าห้องช่าง — เช้า ต่อจาก E01**

น้อยลองบิดลูกบิด ประตูไม่เปิด เธอแตะปลายโลหะที่คาในรูกุญแจ ดึงนิ้วกลับ

**น้อย**  
เหลือแค่นี้ จะไขยังไง

เธอวางกุญแจส่วนหัวที่หักแล้วบนธรณีประตู ยกมือจะเคาะ แต่ลดมือลง

**INT. ห้องช่าง — ต่อเนื่อง**

พี่ชายอยู่ด้านใน ได้ยินเสียงน้อย เขาวางถ้วยโลหะในมือ รีบมาที่ประตู เคาะสองครั้ง

**EXT. หน้าห้องช่าง — ต่อเนื่อง**

น้อยเงยหน้า เธอแนบหูกับประตู

**น้อย**  
ใครอยู่ข้างใน

มือด้านในเคาะอีกครั้ง น้อยเขย่าลูกบิด

**น้อย**  
เปิดให้หน่อยได้ไหม

**INT. ห้องช่าง — ต่อเนื่อง**

พี่ลองลูกบิดจากด้านตัวเอง ประตูยังติด เขาหยุด ออกจากประตูไปหยิบถ้วย ถือไปที่ช่องหน้าต่างเล็ก

**EXT. หน้าห้องช่าง — ต่อเนื่อง**

ขอบถ้วยเคาะขอบหน้าต่าง น้อยหันตาม เดินไปที่ช่อง

พี่ส่งถ้วยออกมาก่อน มือยังจับไว้ น้อยรับถ้วย เห็นใบหน้าพี่อยู่หลังช่อง

**น้อย**  
พี่อยู่ในนั้นเหรอ

พี่พยักหน้า เขาปล่อยถ้วย น้อยมองถ้วยในมือ แล้วมองกลับไปที่ประตู

**น้อย**  
หนูไม่ได้รู้ว่าพี่อยู่ หนูถึง—

เธอหยุด ยื่นถ้วยคืน แต่พี่ยังไม่รับ

น้อยวางถ้วยบนขอบหน้าต่างแทน ขยับมันพ้นช่อง เพื่อให้ทั้งคู่มองกันได้

**น้อย**  
หนูอยู่นี่ก่อน

พี่วางมือบนขอบด้านใน น้อยวางมือบนขอบด้านนอก มืออยู่ใกล้กันคนละฝั่งผนัง ไม่มีใครพยายามลอดช่อง

น้อยเหลือบมองกุญแจหักที่ธรณีประตู แล้วกลับมามองพี่

## บีต / หน้าที่

E02-S010/B01: ยืนยันของเสียและประตูติดก่อนขยับพล็อต  
E02-S020/B02: ผู้ชมรู้ว่าพี่อยู่ข้างในก่อนน้อย; การเคาะทำให้น้อยเปลี่ยนจากคิดว่าไม่มีใครเป็นพยายามสื่อสาร  
E02-S030/B03: ถ้วยมีอยู่ก่อนถูกส่งผ่านหน้าต่าง เป็นการเรียกความสนใจ ไม่ใช่เครื่องมือแก้ล็อก  
E02-S040/B04: น้อยพบพี่และเลือกอยู่คุย ความสัมพันธ์เปิดช่องเล็ก ๆ โดยยังไม่ประกาศคืนดี

การจัดสรรเปิดตอนราว 65–90 วินาที ไม่ได้จับเวลาหรือกำหนดสล็อตตอน; ไม่ใช้การเคาะเท่ากับถอดรหัสข้อความยาว

## คำตัดสินที่ต้องได้จาก Storyteller / ผู้ถือ canon

Outline ระบุ “เธอเข้าไปและคืนดี” แต่ข้อมูลล็อกยังไม่มีวิธีเปิดประตูที่เล่นได้ ขอเลือกอย่างชัดเจนว่า **เลื่อนการเข้าห้องออกไป และให้อีกช่วงของตอนคืนดีผ่านหน้าต่างได้หรือไม่** หากการเข้าห้องใน E02 เป็นข้อบังคับ เจ้าของต้องระบุวิธีทำให้ประตูเดิมเปิดได้ พร้อมเครื่องมือ/ทักษะที่อนุญาตและผลต่อประตูตอนต่อไป ก่อนเขียนเหตุการณ์นั้น

บทนี้หยุดก่อนการตัดสินดังกล่าว ไม่เพิ่มกุญแจ ทางเข้า หรือความสามารถเพื่อให้ outline สำเร็จ การจัดฉากช่องหน้าต่างและที่วางถ้วยเป็นข้อสมมติรอเทียบแบบสถานที่จริง; ยังไม่มีผู้รับยืนยัน
