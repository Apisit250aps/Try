# S07 — ตะกร้าคืน / v2 — R1 implemented

ต้นทาง: v1 สามฉากที่ผู้ใช้ให้ และโน้ต R1 ซึ่งอนุญาตให้แก้ S020 โดยตรง ไม่ต้องขออนุมัติซ้ำ ล็อกความเป็นเจ้าของเรือของพี่ชาย รอยร้าว นักแสดงสองคน และความหมาย S010/S030 สถานะ: บทร่าง v2 พร้อมส่งต่อ ยังไม่มีผู้รับทบทวนหรืออนุมัติ

สมมติฐานจัดฉากเพื่อให้เล่นได้: ใช้ชานบ้านเดียว มีที่วางตะกร้าข้างพี่ชาย ซึ่งหันหน้าออกนอกชานใน S020 จึงยังไม่เห็นของข้างใน ไม่มีการสมมติเหตุที่เรือเสียหรือปูมหลังการจากไป

## บท v2

**S010 — EXT. ชานบ้าน — เย็น**

มะลิวางเรือไม้ที่มีรอยร้าวลงในตะกร้า

**S020 — EXT. ชานบ้าน — ต่อเนื่อง**

พี่ชายนั่งหันหน้าออกจากชาน มะลิถือตะกร้ามาถึงข้างตัวเขา

เธอวางตะกร้าลงในระยะมือเขา ปล่อยหูหิ้ว แล้วหันจะไป

มือของเธอกลับมาจับหูหิ้วอีกครั้ง ยกตะกร้าขึ้นพ้นพื้นเล็กน้อย

มะลิมองเรือในตะกร้า ใช้นิ้วแตะรอยร้าว

เธอวางตะกร้าลงที่เดิม ถอนมือออกจากหูหิ้วช้า ๆ แล้วเลื่อนตะกร้าเข้าหาพี่ชายอีกนิด

เธอออกจากชานไป มือทั้งสองว่าง ไม่หันกลับ

**S030 — EXT. ชานบ้าน — ต่อเนื่อง**

พี่ชายหันมาพบตะกร้า ก้มลงและพบเรือไม้ข้างใน รอยร้าวยังอยู่

## ประวัติฉบับและขอบเขต

v1 ที่รับมาเก็บไว้ในบันทึกนี้: S010 มะลิวางเรือร้าวในตะกร้า; S020 คืนตะกร้าให้พี่แล้วจากไป; S030 พี่พบเรือ ไม่มีการอ้างว่าเคยสร้างไฟล์บท v1 หรือจับเวลาฉบับนั้น

| โน้ต / ฉาก | v1 → v2 | ผลและสถานะ |
| --- | --- | --- |
| R1 / S020 | เพิ่มการจับกลับ ยกเกือบเอาคืน ก่อนวางและถอนมือเอง | ทำให้การทิ้งเรือไว้เป็นการเลือกที่ย้อนใจแล้ว ไม่ใช่เผลอลืม; implemented ตามอำนาจผู้ใช้ |
| S010 / S030 | เก็บความหมายเดิมและ IDs เดิม | ก่อนแก้และหลังแก้ยังเป็นวางเรือในตะกร้า → คืน → พี่ค้นพบ ไม่มีการเฉลยให้พี่รู้ก่อน S030 |

ตรวจจากตัวบทแล้วว่ามีรอยร้าวก่อนและหลัง การสละของเกิดที่ S020 และพี่เพิ่งพบใน S030 นี่เป็นการตรวจโดยผู้เขียน ไม่ใช่ receiver approval หรือหลักฐานว่าผู้ชมอ่านท่าทางสำเร็จ

## เวลาและสถานะที่ได้รับผล

ไม่มีสล็อตกำหนด ประเมิน S010 3–5 วินาที, S020 16–23 วินาที, S030 5–8 วินาที รวม 24–36 วินาที ยังไม่มีการแสดงจับเวลา การเพิ่มความลังเลอาจกิน 7–12 วินาทีเทียบกับการเดินมาวางแล้วจากไป แต่ v1 ไม่เคยถูกวัด จึงไม่ใช่เวลาต่างที่ยืนยันแล้ว

เรือ: ร้าว/เป็นของพี่ตลอด; ตำแหน่งเปลี่ยนจากในตะกร้ากับมะลิเป็นตะกร้าข้างพี่ ไม่เปลี่ยนเจ้าของตามกฎหมายเรื่องที่ล็อกไว้ มะลิ: ถือ → ปล่อย → จับกลับ → เลือกปล่อยจริง → ออกไป พี่: อยู่ตรงนั้นแต่ยังไม่เห็นเรือ → พบเรือหลังเธอจากไป ไม่มีการเพิ่มสถานะคืนดีหรือให้อภัย

## Handoff prepared

- **Artist:** ต้องคงรอยร้าวในรูปเดียวกัน และให้หูหิ้วจับ/ยก/ปล่อยได้จริง ขอคืนข้อจำกัดหากตะกร้าบังนิ้วแตะรอยร้าว ไม่ได้ส่งหรืออ้างชื่อไฟล์ asset
- **Cinematographer:** ผู้ชมต้องรับรู้ว่าเธอยกกลับได้แต่เลือกวาง พี่ต้องไม่เห็นเรือก่อน S030 ขอคืนข้อจำกัดหากภูมิศาสตร์ทำสองเงื่อนไขนี้พร้อมกันไม่ได้ ไม่มีการกำหนดกล้องหรือ coverage
- **Editor:** คงการยกกลับและการถอนมือไว้เป็นคนละความหมาย คงการค้นพบหลังการจากไป ช่วงเวลาคือค่าประเมินสำหรับทดลอง ไม่ใช่ไทม์ไลน์
- **Sound Designer:** ไม่มีบทพูดจำเป็น เสียงวางตะกร้าอาจใช้ย้ำการวางจริงครั้งสุดท้ายได้ แต่ความเข้าใจต้องอยู่ได้จากการกระทำด้วย โปรดคืนข้อจำกัดหากเสียงทำให้ดูเหมือนพี่รู้ก่อน S030; ไม่กำหนดการมิกซ์หรือดนตรี

ยังไม่มีคำตอบจากผู้รับทั้งสี่ และยังไม่อ้างว่าส่งต่อสำเร็จในงานผลิต
