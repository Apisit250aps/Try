# S08 — ที่นั่งหัวหน้า / ตัวอย่างฉากภาพยนตร์ v1

งานต้นฉบับในรูปแบบผู้รับ: ใช้ INT/EXT ชื่อสถานที่ การกระทำ และบทพูดภาษาไทย cue ตัวละครใช้ชื่อไทยคงที่ ไม่มีเลขฉากหรือเลขช็อต สถานะบทร่าง Markdown; ไม่มี PDF export และไม่ได้ยืนยันการแบ่งหน้าตามมาตรฐานผู้รับ

สมมติฐานชั่วคราว: ต้องการกลับสถานะจากหัวหน้าที่วางอำนาจเป็นผู้ต้องรับความช่วยเหลือจากลูกน้องใหม่ ไม่ได้รับต้นฉบับมุกคำพ้องภาษาอังกฤษ จึงเสนอการแทนหน้าที่ตลกนี้ ไม่อ้างว่าเทียบความหมายต้นฉบับครบ

## O.S. / V.O. และมุกแทน

ปราณี O.S. อยู่ในห้องบัญชีที่เปิดถึงสำนักงานเดียวกัน เสียงเกิดในเวลาฉาก เธออยู่นอกส่วนที่กำลังเห็น ไม่ใช่ผู้บรรยาย ขวัญในอนาคต V.O. เล่าย้อนจากอีกสิบปี จึงไม่ใช่คำที่ขวัญปัจจุบันพูดให้สมชายฟัง บทมีอย่างละหนึ่งบรรทัด

มุกแทนคำพ้องใช้ระดับเก้าอี้จริง: สมชายจัดให้ลูกน้องนั่งต่ำ แต่การวางท่าควบคุมทุกอย่างทำให้เขากดเบาะตัวเองลง จนต้องรับคำสั่งง่าย ๆ ว่า “ยืนก่อนค่ะ” จากคนที่เพิ่งถูกจัดให้นั่งต่ำ คันปรับปรากฏก่อนผล จึงไม่เพิ่มกลไกตอนแก้มุก ความสุภาพของขวัญรักษาหน้าที่การช่วยงาน โดยสถานะทางพฤติกรรมสลับกัน ไม่ต้องแปลคำพ้องหรือเพิ่มประโยคอธิบายหลังเบาะลด

## การส่งต่อและข้อจำกัด

เวลาอ่าน/แสดงประเมินราว 55–75 วินาที สมมติให้การพูดเกิดระหว่างเบาะลด เวลารอให้เห็นมือกดคันกับสายตาทั้งคู่ยังไม่ทดสอบ ไม่ได้วัดเสียงหัวเราะ

การเข้าถึง: ส่งบทพูดเป็นฐาน transcript พร้อม speaker IDs ทั้งสามและระบุชั้นเวลาของเสียงขวัญในอนาคต ทีมคำบรรยายต้องแยกผู้พูด O.S. กับผู้เล่าย้อนให้เข้าใจตามข้อกำหนดผู้รับ ทีมคำบรรยายภาพต้องครอบคลุมม้านั่งเตี้ย มือกดคัน เบาะลด และขวัญช่วยยก ไม่บอกสถานะกลับกันล่วงหน้าก่อนการกระทำ ขอให้ Editor/ทีมเข้าถึงทดลองวางคำบรรยายภาพระหว่างช่วงว่าง หรือเตรียมเวอร์ชันบรรยายแยก เพราะช่วงเสียงซ้อนยังไม่ถูกวัด

ไม่ใส่คำอธิบายเหล่านี้เพิ่มในบทหลัก ไม่อ้างความสอดคล้องมาตรฐานการเข้าถึงจากตัวบทเพียงอย่างเดียว ผู้รับยังไม่ได้ตรวจรูปแบบหรือยืนยัน handoff
