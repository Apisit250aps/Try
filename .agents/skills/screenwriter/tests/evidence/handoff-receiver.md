# ที่ว่างข้างกระถาง — บทแอนิเมชันฉบับรับช่วง v1

ต้นทางที่อ่านจริง: `/tmp/screenwriter-handoff-trial/input.md` ซึ่งส่งงาน Storyteller ชื่อเดียวกัน draft v1, narrative B01–B05 มาให้ สถานะต้นทางเป็นร่างที่ผู้เขียนตรวจเอง ยังไม่ใช่ canon อนุมัติ บทรับช่วงนี้ก็เป็น **บทร่างดัดแปลง ยังไม่อนุมัติ** ไม่ยกระดับสถานะต้นทาง

เป้าหมาย 45 วินาที เด็กสองคน โต๊ะปลูกต้นไม้แห่งเดียว ไม่มีบทพูด VO หรือข้อความอ่านได้ เลือกตีความ “silent” เป็นไม่มีเสียงใดในเวอร์ชันหลัก รวมดนตรีและเสียงสิ่งของ ไม่ใช้เสียงพาความหมาย

ข้อสมมติการจัดฉาก: เรียกเด็กตามหน้าที่ว่า **เด็กหนึ่ง / เด็กสอง** โดยไม่เพิ่มประวัติ ใช้กระถางทรงเหลี่ยมเพื่อให้แนวตรงกับแนวเฉียงอ่านจากรูปทรงได้ มีถ้วยตักดินสองใบ ดิน เมล็ด และบัวเล็กที่ทั้งสองถือหูร่วมกันได้ วางทุกอย่างบนโต๊ะตั้งแต่ต้น

**จุดไม่สอดคล้องที่รับมา:** B02 ระบุเด็กหนึ่งใส่ดินทั้งสองกระถาง แต่ B03 เรียกกระถางที่ส่งให้เพื่อนว่า “กระถางว่าง” ฉบับเล่นได้ด้านล่างใช้กระถางเดิมที่มีดินชั้นแรกและยังปลูกไม่เสร็จ ไม่ทำให้ดินหายหรือเพิ่มกระถางที่สาม นี่เป็นการตีความชั่วคราวที่เปิดเผยไว้ รอคำยืนยันของ Storyteller ไม่ใช่ข้อเท็จจริงใหม่ที่อนุมัติแล้ว

## บท

**EXT. โต๊ะปลูกต้นไม้ — กลางวัน**

เด็กทั้งสองนั่งข้างกัน กระถางเหลี่ยมสองใบ ถ้วยสองใบ ดิน เมล็ด และบัวเล็กอยู่บนโต๊ะ ไม่มีตัวหนังสือบนอุปกรณ์

เด็กหนึ่งจัดกระถางให้ตรงขอบโต๊ะ เด็กสองขยับกระถางใบใกล้ตัวเข้าหาตน เด็กหนึ่งยกใบนั้นกลับมาจัดให้ตรงกับอีกใบ

เด็กสองวางมือลงบนตัก

เด็กหนึ่งตักดินใส่กระถางของตัวเอง เด็กสองหยิบถ้วยอีกใบ ตักดินยื่นให้ เด็กหนึ่งรับถ้วยมา เทดินส่วนหนึ่งลงใบตัวเอง ที่เหลือลงใบของเพื่อน กระถางทั้งสองมีดินเพียงชั้นแรก

เด็กสองนั่งรอ ครั้นถ้วยว่างถูกวางลง เขาตักดินเตรียมไว้อีกถ้วย

เด็กหนึ่งเอื้อมไปทางถ้วยที่เตรียมไว้ มือหยุดเหนือมัน เขามองมือของเพื่อน

เขาวางถ้วยว่างอีกใบตรงหน้าเด็กสอง แล้วเลื่อนกระถางของเพื่อนกลับไปให้ เลื่อนกระถางตัวเองมาอยู่ตรงหน้าตัว

เด็กสองยกถ้วยที่ตนเตรียมไว้ เติมดินลงกระถางของตัวเอง เด็กหนึ่งเริ่มปลูกในใบของตน

เด็กสองหยิบเมล็ด เมล็ดหลุดจากนิ้ว กลิ้งมาติดขอบนอกกระถางบนโต๊ะ

มือเด็กหนึ่งยื่นไปทางกระถางเพื่อนเหมือนตอนจัดใหม่ เขาหยุด ถอนมือกลับมาวางข้างกระถางตัวเอง

เด็กสองหยิบเมล็ดที่ตก ใส่ลงในกระถาง กลบดินด้วยมือตัวเอง เด็กหนึ่งกลบดินของตนจนเสร็จ

เด็กสองเลื่อนกระถางขึ้นไปด้านหน้าของโต๊ะ วางเฉียงออกจากแนวขอบ

เด็กหนึ่งยกกระถางของตนไปวางข้างกัน ขอบใบของเขาตรง ส่วนใบของเพื่อนยังเฉียง เขาไม่แตะกระถางเพื่อน

เด็กหนึ่งเลื่อนบัวเล็กมาไว้ตรงกลาง ปล่อยหูไว้ให้เด็กสองจับ เด็กสองจับหูด้านหนึ่ง เด็กหนึ่งจับอีกด้าน ทั้งสองยกและเอียงบัวด้วยกัน รดกระถางสองใบที่ยังวางต่างแนว

## แผนเชื่อมบีตต้นทางกับบท

ใช้ scene ID **S010** สำหรับฉากเดียว และ scene-beat IDs **SB01–SB05** เป็นรหัสท้องถิ่นของบทรับช่วง ไม่ใช่หมายเลขช็อต รักษา narrative IDs เดิมครบ

| Narrative → scene / scene beat | สิ่งที่เกิดและความหมายที่รักษา | หน้าต่างจัดสรร / ช่วงประเมิน |
| --- | --- | --- |
| B01 → S010/SB01 | เด็กหนึ่งจัดซ้ำหลังเพื่อนลงมือ; เพื่อนเก็บมือบนตัก ตั้งรูปแบบควบคุมงาน | 0–7 วินาที / 6–8 วินาที |
| B02 → S010/SB02 | รับถ้วยเพื่อนแล้วใส่ดินเองทั้งสองใบ เพื่อนยังเป็นเพียงผู้ส่งของ | 7–15 / 7–10 |
| B03 → S010/SB03 | ไม่คว้าถ้วยที่เตรียมไว้; จัดถ้วยและกระถางคืนพื้นที่ให้เพื่อน พร้อมแยกงานตัวเอง | 15–25 / 8–11 |
| B04 → S010/SB04 | เมล็ดหล่น มือเกือบแทรก แต่ถอนกลับ เพื่อนแก้เองจนกลบดินเสร็จ | 25–36 / 10–14 |
| B05 → S010/SB05 | ไม่จัดกระถางเฉียงใหม่; วางของตัวเองข้างกัน แล้วแบ่งหูบัวทำงานร่วม | 36–45 / 9–12 |

ผลก่อน–หลัง: การจัดของเพื่อนใหม่ใน SB01 ถูกตอบด้วยการปล่อยของเพื่อนไว้ตามเดิมใน SB05 ส่วนการรับถ้วยไปทำทั้งสองใบใน SB02 ถูกตอบด้วยการแบ่งงานและแบ่งหูบัว เด็กหนึ่งเป็นผู้หยุดแทรก เด็กสองเป็นผู้แก้เมล็ดหล่น ไม่ย้ายความสามารถแก้ปัญหากลับไปให้เด็กหนึ่ง

เวลา 45 วินาทีเป็นการจัดสรรเป้าหมาย ไม่ใช่ผลจับเวลา ช่วงประเมินรวมตามลำดับประมาณ **40–55 วินาที** สมมติให้ท่าตักดินสั้น มือเอื้อมถึงอุปกรณ์ได้ทันที และเด็กหนึ่งทำกระถางตัวเองระหว่างที่เพื่อนทำ ไม่บวกเวลางานสองคนที่เกิดพร้อมกันซ้ำ ไม่มีการอ่านแสดงหรือแอนิแมติก หากเกินสล็อต ลดจำนวนครั้งตักดินหรือระยะเลื่อนของก่อนลดจังหวะมือหยุดกับการไม่จัดกระถางเฉียงใหม่

## Continuity และสิ่งที่ต้องส่งต่อ

- **จำนวนและสถานะ:** มีเด็กสองคน กระถางสองใบเดิมตลอด ดินชั้นแรกจาก SB02 ยังอยู่เมื่อส่งคืนใน SB03 เมล็ดหล่นบนโต๊ะแล้วถูกเด็กสองเก็บคืน ไม่มีการงอกทันทีหรือเปลี่ยนรูปกระถาง บัวมีน้ำอยู่ก่อนเริ่มยก
- **ความรู้และการเห็น:** เด็กหนึ่งต้องเห็นเมล็ดตกก่อนเอื้อม ผู้ชมต้องเห็นมือเพื่อนแก้เองหลังมือเด็กหนึ่งถอน SB01 ต้องอ่านการจัดซ้ำได้ก่อน SB05 จะมีความหมาย ไม่ใช้สีหรือรายละเอียดจิ๋วเป็นหลักฐานเดียว
- **Artist / animation:** ต้องออกแบบถ้วยกับบัวให้มือเด็กจับได้จริง และท่าถือหูคนละด้านไม่บังการแบ่งแรงหรือดูเหมือนแย่งบัว ความยากเรื่องนิ้ว เมล็ด และน้ำเป็นข้อควรทดลองในเครื่องมือจริง ยังไม่ใช่ขีดจำกัดที่วัดแล้ว
- **Cinematographer:** ต้องคงการเห็นเมล็ด–มือยื่น–มือหยุด–เพื่อนแก้ กับแนวกระถางก่อน/หลัง ขอคืนข้อจำกัดหากภูมิศาสตร์หรือขนาดเมล็ดทำให้ลำดับอ่านไม่ได้ ไม่ได้กำหนดช็อต เลนส์ หรือ coverage
- **Editor:** รักษาความต่างระหว่าง “รอรับงานคืน” กับ “ยอมให้เพื่อนทำต่อ” และผลตอบของกระถางสองแนว เวลาข้างต้นไม่ใช่ไทม์ไลน์ตัดต่อ
- **Sound Designer / การเข้าถึง:** เวอร์ชันหลักเงียบ ไม่มีเสียงบอกเมล็ดตก เตรียมความต้องการคำบรรยายภาพแยกสำหรับผู้ไม่เห็นภาพ ครอบคลุมมือที่ถอนกับของเพื่อนที่ไม่ถูกจัดใหม่ โดยไม่เติม VO ลงเวอร์ชันหลัก

## คำถามเปิดที่เจาะจง

1. **Storyteller:** ยืนยันได้หรือไม่ว่า “กระถางว่าง” ใน B03 หมายถึงกระถางเดิมที่มีดินชั้นแรกแต่ยังปลูกไม่เสร็จ ตามบทนี้? หากต้องว่างจากดินจริง โปรดเลือกแก้ B02 หรือ B03 เพราะการรักษาสองข้อความตามตัวอักษรพร้อมกันจะผิดความต่อเนื่อง
2. **Storyteller / Director:** ตีความ “เอียง” ใน B05 เป็นการวางกระถางเหลี่ยมเฉียงแนวบนฐานที่มั่นคงได้หรือไม่? ฉบับนี้ใช้ความต่างของแนวเพื่อให้การไม่แก้งานอ่านได้ โดยไม่เพิ่มเหตุจะล้ม หากต้องเป็นการตั้งเอียงจริง ต้องกำหนดฐานรองและผลต่อการรดน้ำให้สอดคล้อง
3. **Artist / ทีมแอนิเมชัน:** บัวขนาดที่เลือกทำให้เด็กจับหูคนละด้านและรดทั้งสองใบได้ชัดในช่วงประมาณ 5 วินาทีหรือไม่? หากไม่ได้ ขอคืนรูปแบบการจับหรือเวลาที่ต้องเพิ่มก่อนแก้ SB05; ไม่ลบการทำร่วมกันเอง

การถามนี้ไม่ขวางการใช้บทร่างทดลอง แต่ต้องปิดข้อ 1 ก่อนล็อกความต่อเนื่อง และปิดรูปแบบอุปกรณ์ก่อนผลิตจริง สถานะคือ **handoff prepared**: อ่านและดัดแปลง artifact จริงแล้ว ยังไม่มีคำตอบยืนยันจากเจ้าของต้นทางหรือผู้รับ ไม่มีการผลิตภาพยนตร์หรืออ้างผลตรวจความเข้าใจผู้ชม
