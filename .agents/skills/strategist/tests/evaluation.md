Date: **2026-11-26**. Scope: Strategist only. This record distinguishes actual
offline execution, same-author model text trials and work requiring real data.
Research-first does not mean a source count establishes mastery; Practice-tested
does not mean a fixture establishes audience performance.

| Audience/experiment/platform practice | **Not performed**: no account/export dataset, recruited study, native A/B experiment, real post, receiver execution or revenue evidence supplied | no performance, eligibility, monetization, causal lift or production-readiness claim |

## Reproduce offline checks

From repo root:

```bash
python3 scripts/validate_repository.py --root skills/strategist --self-test
python3 scripts/validate_repository.py --self-test
python3 skills/strategist/tests/check_example.py
```

Skill Creator's `quick_validate.py` requires PyYAML. This run used a temporary
virtual environment `/tmp/strategist-validation-venv` with PyYAML; pypdf/PyMuPDF
were used only there for research scan inspection. No dependency files changed.
UI YAML is parsed separately for strings, description length and `$strategist`
invocation. A temporary complete copy is checked without any sibling folders.

The example checker is deliberately specific to the synthetic fixture, not a
production schema. It rejects false measured/published/executed/accepted states,
unsupported cross-platform ranking or audience sums, duplicate IDs, unregistered
sources, wrong/zero/unknown rate bases, invalid counts and wrong AVD/APV arithmetic.
The source trace expands ID ranges and checks all package Markdown references
against P01–P12 and S01–S30; this proves resolvability, not that a citation entails
a claim. Entailment and limits were reviewed in the claim map by the author.
