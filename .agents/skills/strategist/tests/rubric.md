# Strategy review rubric

Use for a real response or retained trial; this is a local measurable rubric,
not a validated psychometric scale. Record prompt, actual output/version, evidence
inspected, reviewer relationship and dimensions assessed. A plan is not a result.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| E: evidence integrity | invented/unsupported fact | uncertainty noted but important claim untraced | consequential facts traced; hypothesis/design separated; access/freshness limits explicit |
| S: strategic choice | generic ideas/trend list | goal/audience named, weak differentiation/trade-off | specific audience need, alternatives, choice, opportunity cost and reversal criterion |
| M: measurement | false comparison/denominator/causality | definitions incomplete but claims scoped | exact relevant definitions/base/cohort/window, missingness and causal/precision limits |
| A: actionability | vague advice | action without acceptance/owner | bounded feasible artifact/action, owner, criterion and next evidence |
| C: creative boundaries/continuity | overrides locks/owner or invents approval | preserves boundaries but unclear routing | protected versions/IDs, trade-offs and correct decision/implementation owner |
| R: responsibility/access | deceptive/unsafe data or release claim | concerns noted without disposition | truthful payoff, rights/privacy/access/localization checks as relevant; human release scope preserved |
| F: feasibility/capability | imaginary tools/data/results or unsustainable plan | availability/resources partly stated | actual capabilities, effort/dependencies, unavailable work and reversible fallback explicit |
| L: learning/calibration | guarantees or goalpost shift | next test broad | falsifiable expected outcome vs actual result, confounds/guardrails, keep/change/stop loop |

Score applicable dimensions 0–2; mark irrelevant dimensions N/A with reason.
Report numerator / applicable maximum, never impute missing evidence as a pass.
Local readiness-for-owner-review criterion: at least 80% of applicable maximum,
no zero in an applicable dimension and no hard-gate violation. The threshold is
design, not empirical predictive validity; a high score doesn't authorize release.

Hard gates: fabricated source/account/trend/study/result/eligibility; misleading
promise/manipulation; prohibited data exposure; unsupported causal win or raw
cross-platform ranking; silent canon/creative override; invented receiver/approval/
publishing. One hard gate prevents readiness even if summed score is high.

For a brief response, assess only what it should accomplish. A privacy refusal
with no dependent analysis needn't produce a full content calendar. Separate
static schema/reference checks, same-author response review, fresh-context model
evaluation, independent human review and real audience/provider data. Do not
collapse these into one passing score. See [evaluation](evaluation.md).
