# From strategy to insight and back

P06/P10/P12 in [notes](../research/notes.md).

1. Before production, choose the audience/job, promise and priority goal. Log
   alternatives, baseline (or absent), cost ceiling, expected direction, decision
   criterion, creative locks and next owners in the versioned brief.
2. Before distribution, map episode → approved cut → localized/platform variant
   → post ID. Verify data availability, metric dictionary, observation windows,
   privacy and release authority. A planned post is not published evidence.
3. During learning, preserve snapshots/export dates and exact definitions. Check
   coverage/lag/missingness/changed counting rules. Keep paid vs organic and source
   cohorts separate. Inspect actual material before inventing creative diagnoses.
4. Triangulate behavior with qualitative evidence. Code comments/interviews into
   needs, comprehension, affect, context and unwanted effects; retain negative
   cases, sampling/recruitment and uncertainty. Quote minimally and anonymize.
   A commenter's interpretation is evidence about that response, not the whole
   audience. Do not claim community listening occurred without actual material.
5. Report observation → possible explanations → recommendation → distinguishing
   next evidence. For experiments add assignment/data quality, estimates/precision,
   guardrails and stop-rule adherence. If underpowered or confounded, say
   inconclusive; keep decisions proportional to the evidence and reversible.
6. Prioritize by goal impact, confidence, effort, dependencies and downside.
   Separate urgent rights/data defects, inexpensive clarifications, creative
   options needing Director choice and larger research investments. Give each
   action an owner, rationale, cost, deadline/review point and acceptance condition.
7. Strategy review: keep/iterate/park/stop each pillar/series against the original
   goal and budget. Compare expected vs measured outcomes without moving goalposts;
   explain changed goals explicitly. Update personas only where evidence warrants,
   version the strategy, mark affected handoffs stale, and request receiver checks.

Example: high CTR and early exit supports examining promise/context mismatch,
not “make every shot faster.” Return a located question to Director/Editor,
preserve the original variant, then recheck comparable audience/source/window.
If a proposed fix alters canon, route to Storyteller as well. An insight report
does not overwrite the cut, issue independent Critic approval or publish a variant.
